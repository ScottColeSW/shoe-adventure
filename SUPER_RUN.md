# Super Run — Spectator Sequence

The **Super Run** is a deterministic cinematic autopilot rather than a remote model call. This keeps the mode instant, reliable, playable offline, and easy to watch at any screen size while still presenting a clear AI-style performance. When launched, Right Shoe takes control of the route, the player input is ignored until the run ends, and the HUD changes to show the current showcase move.

| Beat | Route decision | Visible payoff |
| --- | --- | --- |
| Lace-Up Launch | Sprint from the bedroom threshold and collect the opening button trail. | Coral lace trail and “AI ROUTE: LOCKED” status. |
| Feather Flight | Collect the Wingtip Feather before the first raised shoebox. | Automatic double jump over the shoebox lip. |
| Lace Dash | Collect the dash spool and accelerate across the laundry lane. | Coral dash streak and stitched particle burst. |
| Sole-Flip Kick | On approach to the lace goblin or roller skate, jump, rotate, and stomp. | “SOLE-FLIP KICK” callout, slow-motion flash, and enemy defeat sparks. |
| Moon Insole | Take the Moon Insole in the final section. | Nearby enemies slow while Right Shoe surges toward the tower. |
| Reunion Finish | Cross the rescue threshold and reach Left Shoe. | Heart burst, enlarged rescue halo, and a “PAIR RESTORED” finale. |

The autopilot will favor visible power-ups and timed jumps over speed-running shortcuts. It will queue one special kick for the first grounded enemy and one for the first roller skate, preserve enough momentum for the lace bridge, and force the victory path even if collision timing varies slightly between browsers.
